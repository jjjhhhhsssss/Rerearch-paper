# 논문 검색

키워드로 선행연구 논문을 찾고, 논문마다 Results·Discussion 핵심 문장을 뽑아 보여 주는 웹 페이지입니다. 원하는 논문의 요약만 골라 PDF 한 파일로 내보낼 수 있습니다.

## 기능
- **여러 키워드 검색 (최대 5개)**: 하나라도 포함된 논문을 모두 가져오고, 논문마다 어떤 키워드가 어디(제목 / 초록 / 색인·본문)에 들어 있는지 표시
- **키워드 필터**: 키워드를 켜고 끄며 결과 좁히기
  - 합쳐서 보기: 켠 키워드 중 *하나라도 포함* 또는 *모두 포함*
  - 키워드별로 나눠 보기: 키워드마다 따로 묶어서 보기
  - 제목에 포함된 것만 보기, 정렬(관련도 / 포함 키워드 수 / 최신 / 피인용)
- **검색 소스 선택**: 7개 DB 중 골라서 검색. DB마다 다루는 분야 키워드가 붙어 있고, 분야 버튼을 누르면 그 분야 DB만 선택됨. 링크에 `&s=pubmed,eric`처럼 남음
- **페이지 나누기**: 결과를 30편씩 나눠 보기. 쪽 번호(1~10, 다음)는 목록 위·아래 두 곳에 표시 (키워드별 보기에서는 키워드마다 따로)
- **검색 결과 이어서 보기**: 처음에는 키워드·DB마다 설정한 건수만 받고, 마지막 쪽에서 "다음"을 누르면 각 DB에서 다음 묶음을 이어서 받아 옴. 상태줄에 DB가 알려 준 전체 검색 건수를 표시 (API 제한: 대부분 1만 건, DOAJ 1천 건까지)
- **발행 연도 범위**: 시작~끝 연도 지정 (한쪽만 넣어도 됨). 링크에 `&y=2018-2022`로 남아 같은 조건으로 공유 가능
- **Results·Discussion 요약 (본문 기반 + 초록 기반)**
  - 본문을 확인할 수 있는 논문은 본문의 Results·Discussion 섹션에서 뽑은 문장과 초록에서 뽑은 문장을 함께 표시
  - 본문이 없으면 초록(구조화 초록의 Results·Conclusions, 아니면 초록 앞·뒤 구간)에서만 추출하고 그 사실을 표시
  - OpenAlex 결과도 DOI로 Europe PMC 본문을 찾아 연결
  - 초록 요약을 먼저 보여 주고, 본문 요약은 도착하는 대로 채움
- **링크**: DOI, Europe PMC, PMC 전문, OpenAlex, Google Scholar
- **PDF 내보내기**: "PDF에 담기"로 고른 논문만 모아 제목·저자·링크·키워드·요약을 A4 PDF로 저장 (고른 목록은 브라우저에 저장돼 새로고침해도 유지)

## 데이터 출처
| 소스 | 분야 | 비고 |
|---|---|---|
| [Europe PMC](https://europepmc.org) | 의학·생명과학 중심 | 오픈액세스 논문 본문(JATS XML) 제공 |
| [OpenAlex](https://openalex.org) | 전 분야 | 초록 제공, PMC 번호가 있으면 본문도 사용 |
| [PubMed](https://pubmed.ncbi.nlm.nih.gov) | 의학·간호·치의학·수의학 | 구조화 초록 제공 |
| [PLOS](https://plos.org) | 생명과학·의학·자연과학 | 오픈액세스, 본문은 PMC로 연결 |
| [DOAJ](https://doaj.org) | 전 분야 | 오픈액세스 저널 |
| [ERIC](https://eric.ed.gov) | 교육학 | 일부 무료 원문 PDF |
| [CiNii](https://cir.nii.ac.jp) | 전 분야 (일본) | 일본어 키워드 검색 가능 |
| Google Scholar | 전 분야 | 공식 API가 없어 결과는 가져오지 않고, 같은 검색과 논문별 검색 링크만 제공 |

## 요약 방식
AI(LLM)를 쓰지 않는 **추출 요약**입니다. 문장마다 점수를 매겨 높은 문장 2~3개를 원래 순서대로 보여 줍니다.
- 검색 키워드가 들어간 문장 +3
- Results: 수치·%·p값, `significant`, `increased`, `compared` 같은 결과 표현
- Discussion: `suggest`, `indicate`, `conclude`, `limitation` 같은 해석·결론 표현

API 키나 서버가 필요 없어서 GitHub Pages에서 그대로 동작합니다. 대신 원문의 문장을 그대로 가져오는 방식이므로, 인용하기 전에는 원문을 꼭 확인해야 합니다.

## 개인정보·보안
- API 키, 비밀번호, 로그인이 필요 없고 코드에 들어 있는 비밀 값이 없습니다.
- 서버가 없어서 검색어나 고른 논문이 어디에도 저장·수집되지 않습니다. "PDF에 담기" 목록은 사용하는 사람의 브라우저(localStorage)에만 남습니다.
- 검색어는 고른 검색 소스(Europe PMC, OpenAlex, PubMed, PLOS, DOAJ, ERIC, CiNii)의 공개 API로만 전송됩니다. 키가 필요한 API는 쓰지 않습니다.
- `.gitignore`로 `.env`, 키 파일, 내보낸 PDF 등이 저장소에 올라가지 않게 막아 두었습니다.

## 알아둘 점
- Europe PMC 본문 서버는 한 건에 10~20초 걸릴 때가 있어 본문 요약이 늦게 뜰 수 있음
- OpenAlex는 접속하는 사람(IP)마다 요청 한도가 있어, 짧은 시간에 검색을 많이 하면 잠시 막힐 수 있음 (자동으로 다시 시도)

## 실행
정적 파일(HTML/CSS/JS)만으로 되어 있습니다.
- GitHub Pages: 저장소 Settings → Pages → Branch `main` / `(root)` 지정 후 `.../paper-search/` 주소로 접속
- 로컬: 아무 정적 서버로 이 폴더를 열면 됩니다 (`file://`로 직접 열면 브라우저에 따라 요청이 막힐 수 있음)

## 파일
- `index.html` 화면 구조
- `style.css` 스타일 (라이트/다크 모드)
- `app.js` 검색, 결과 병합(DOI·제목 기준 중복 제거), 필터, 선택, PDF 내보내기
- `summarize.js` 본문 섹션 파싱과 추출 요약
